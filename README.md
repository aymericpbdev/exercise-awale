# Awalé - Projet collaboratif de développement web

## Description

Implémentation web du jeu traditionnel africain Awalé, développé en équipe dans le cadre de notre formation Web & Mobile Developer à l'AFEC d'Agen.

---

## 📋 À propos du projet

### Contexte

Ce projet a été développé par une équipe de 4 apprenants dans le cadre de la formation Titre Professionnel Développeur Web & Web Mobile à l'AFEC.

### Technologies utilisées

- **HTML5** - Structure du jeu
- **JavaScript (Vanilla)** - Logique du jeu et interactivité
- **Git/GitHub** - Gestion de version et collaboration

### Fonctionnalité principale

Version web du jeu Awalé permettant à deux joueurs de s'affronter en local sur le même navigateur.

---

## 🎯 Objectifs pédagogiques

L'objectif principal de ce projet était d'apprendre à travailler efficacement en équipe sur un projet de développement web en utilisant des outils et pratiques professionnalisantes.

### Compétences travaillées

- **Gestion de version avec Git/GitHub**
  - Création et gestion de branches
  - Merge de code et résolution de conflits
  - Protection de la branche principale

- **Workflow collaboratif**
  - Pull requests et code review
  - Validation par le responsable avant intégration
  - Communication asynchrone via GitHub

- **Organisation de projet**
  - Utilisation de GitHub Projects avec tableau Kanban
  - Gestion et suivi des issues
  - Répartition et priorisation des tâches

- **Gestion d'équipe**
  - Définition des rôles et responsabilités
  - Coordination entre les membres
  - Respect des délais

- **Livraison en temps contraint**
  - Définition d'un MVP (Minimum Viable Product)
  - Priorisation des fonctionnalités essentielles
  - Respect de la deadline

  - morgandevmh - Secrétaire et faiseur d'idées
  - marwanahemm - Batisseur d'HTML
  - DavidBairet - Boucleur de JavaScript

### Méthodologie de travail

#### Workflow Git/GitHub

1. Branche `main` protégée (merges uniquement via pull request)
2. Création de branches feature pour chaque fonctionnalité
3. Pull request avec description détaillée
4. Review et validation par le responsable
5. Merge vers `main` après approbation

#### Gestion de projet

- **GitHub Projects** : tableau Kanban pour suivre l'avancement
- **GitHub Issues** : documentation des tâches et bugs
